# Сайт-портфолио Ольги Чудиновой

Статический сайт: HTML, CSS, Vanilla JS. `index.html` лежит в корне.

## Что заменить
- Фото: файл `assets/olga-photo.jpg` (просто замените файл, имя оставьте).
- Контакты: в `index.html` найдите `your-email@example.com` и `your_username`.
- Кейсы: блок `<section id="cases">`, тексты карточек.

## Публикация на GitHub Pages
1. Загрузите все файлы в корень репозитория (ветка `main`).
2. Settings → Pages → Source: Deploy from a branch → Branch: `main`, папка `/ (root)` → Save.
3. Через 1-2 минуты сайт откроется по адресу `https://ВАШ-ЛОГИН.github.io/НАЗВАНИЕ-РЕПОЗИТОРИЯ/`.
