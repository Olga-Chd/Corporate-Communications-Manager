# Olga's Communication Hub

Создай современный персональный сайт-портфолио: Менеджер по внутренним коммуникациям Ольга Чудинова.
Сайт должен продавать экспертизу специалиста и создавать ощущение сильного senior/middle+ специалиста по внутренним коммуникациям и контенту с опытом 5+ лет в IT-компаниях (B2B, B2G). Занимаюсь развитием внутренних каналов коммуникации, созданием контента, организацией мероприятий и проектами по вовлеченности сотрудников. Умею выстраивать системную коммуникацию внутри компании, транслировать ценности и повышать вовлеченность через контент, digital-инструменты и события.
Основная цель сайта — показать потенциальному работодателю мой опыт, подход к работе и реальные маркетинговые кейсы.

1. Информация обо мне:
Имя: Ольга Чудинова.
Позиционирование: Менеджер по внутренним коммуникациям и бренду.
Опыт: 5+ лет в IT-компаниях, последние 3 года работаю с корпоративной культурой и брендом.
Ключевая экспертиза: 
- Внутренние коммуникации (рассылки, дайджесты, корпоративные каналы),
- Контент и сторителлинг (копирайтинг, редактура, визуал), 
- Развитие HR-бренда и корпоративной культуры, 
- Организация корпоративных мероприятий (онлайн/офлайн), 
- Вовлечение сотрудников (интерактивы, опросы, активности), 
- Корпоративные digital-каналы (Telegram, сайт, внутренние порталы),
- Работа с подрядчиками и бюджетами,
- Проведение опросов и анализ обратной связи,
- Управление коммуникационными проектами.

2. Структура лендинга: 
Первый экран, обо мне, кейсы, навыки, подход к работе, контакты. Добавь фиксированную или sticky-навигацию. Навигация: Обо мне / Кейсы / Навыки / Контакты. На мобильной версии сделать компактное hamburger-меню.

3. Визуальное направление: 
Сделай сайт визуально похожим на современное digital-портфолио сильного специалиста. Не использовать шаблонный дизайн «резюме на сайте». 
Стиль: минималистичный, premium, современный digital, много воздуха, выразительная типографика без курсива, крупные заголовки, асимметрия там, где она помогает дизайну, небольшие интерактивные детали, визуальная иерархия.
Предпочтительная цветовая гамма: основной фон — холодный лаймовый цвет, основной текст — почти черный, темно-серый, акцент — глубокий оранжевый, дополнительные оттенки — серый, графитовый, приглушенный оранжевый. 
Не делать сайт полностью синим. Акцентный цвет использовать для: CTA, ссылок, небольших графических элементов, номеров кейсов.
